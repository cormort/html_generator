# Project Index

## Project Overview
HTML Editor Ultimate · Pro is a three-separate version (`index.html` / `editor.js` / `styles.css`) enhanced HTML editor. It offers several advanced features such as AST precise replacement, switchable editors (Monaco & CodeMirror), multi-file infinite tabs with automatic localStorage saving, Markdown/HTML preview with click-to-sync positioning, responsive design, resizer, and multiple themes (Light/Material/Dracula). The project is designed to be user-friendly and efficient, making it a valuable tool for developers.

## Key Modules
1. **index.html**: This file serves as the page skeleton, loads external libraries, and provides the main container for the editor.
2. **editor.js**: This is the core script that handles various functionalities including AST replacement, switching between Monaco and CodeMirror editors, managing tabs, previewing content, generating an outline, and resizing features.
3. **styles.css**: This file contains theme variables, BEM styling conventions, responsive design principles, and visual styles to ensure a consistent and aesthetically pleasing user interface.

## Technologies Used
- **HTML/CSS/JavaScript**: The core technologies used for building the web application.
- **Monaco Editor**: A powerful code editor developed by Microsoft, providing features like IntelliSense, syntax highlighting, and more.
- **CodeMirror**: A lightweight code editor that is easy to integrate and customize.
- **AST (Abstract Syntax Tree)**: Used for precise replacement of JavaScript functions and CSS rules based on their structure.
- **localStorage**: For saving the state of open tabs and content across browser sessions.
- **Responsive Design**: Ensures the editor works well on various devices and screen sizes.

This project is a comprehensive tool for developers looking to enhance their HTML editing experience with advanced features and flexibility.
